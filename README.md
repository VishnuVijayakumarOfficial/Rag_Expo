# Rag Expo

**Explore • Learn • Experience**

A modern, responsive AI Assistant UI for exploring different Retrieval-Augmented Generation (RAG) architectures:
- Native RAG
- Advanced RAG
- Modular RAG
- Graph RAG
- Hybrid RAG
- Agentic RAG
- Corrective RAG
- Self-RAG
- Adaptive RAG
- Multimodal RAG

## Features

- **Interactive AI Assistant**: Chat with the RAG assistant mascot and explore grounded answers.
- **RAG Architecture Tabs**: Fast category switching across all 10 RAG paradigms.
- **Document Ingestion Simulator**: Drag & drop or sample document indexing modal.
- **Theme Switcher**: Smooth light and dark mode toggling.

## Development

```bash
# Run local development server
npm run dev

# Run Oxlint
npm run lint

# Build for production
npm run build

# Preview production build
npm run preview
```
